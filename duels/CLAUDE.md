# duels module

`Duels` wires everything (the `JavaPlugin` only starts and stops it, so tests run it on a mock plugin). Packages: `arena` (YAML registry; arenas have categories that kits pick from, an optional center and build limit; `ArenaInstances` lends arenas to duels, one at a time, puts back blocks changed by build kits from `ArenaChanges`, and rebuilds arenas a crash left changed from `ArenaTemplate` snapshots; `ArenaPregen` pastes read-only copies of an arena's snapshot on a grid in the void `ArenaWorld`, and a copy is rebuilt from its source's snapshot at its offset), `kit` (YAML registry), `state` (`PlayerSnapshot` saved to the database before a duel touches a player, restored after; leftovers restored at login), `stats` (wins, streaks and one global Elo rating in `duels_stats`; rating changes are written as deltas), `match` (`MatchManager` lifecycle, `RequestManager`, `QueueManager` with an unranked FIFO queue and a ranked rating-range queue per kit, `Rewards`; only ranked-queue duels move ratings), `listener` (combat rules, protections, build rules and block recording, sessions), `menu`, `command`, `hook` (Vault and PlaceholderAPI, each behind a nested class so they stay optional). Main code compiles with `-Xlint:deprecation -Werror`. User docs in `duels/README.md`.
